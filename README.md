# ⚽ Calculadora Junior

Calculadora web hecha con HTML, CSS y JavaScript, inspirada en los colores del Junior de Barranquilla (rojo, blanco y azul).

## 🚀 Funciones

- Operaciones básicas (+, −, ×, ÷)
- Soporte para decimales
- Diseño responsivo y temático

## 🛠 Tecnologías

- HTML5
- CSS3 (Grid, variables)
- JavaScript puro

## ▶️ Uso

Abre `index.html` en tu navegador.
